# UK RoadPulse Intelligence

A live road disruption and transport operations
intelligence platform for the United Kingdom.

## Project objectives

- Integrate TfL and National Highways data.
- Automate incremental data ingestion.
- Preserve historical disruption records.
- Implement data validation and quality checks.
- Build a public road monitoring web application.
- Deploy using free or student-funded cloud services.
- Measure data freshness, reliability and usage.

## Technology

Python, SQL, Azure, GitHub Actions, Flask,
JavaScript, Leaflet and cloud database services.

## Development status

Phase 1: Source connectivity and feasibility testing.

## Data providers

- Transport for London
- National Highways
